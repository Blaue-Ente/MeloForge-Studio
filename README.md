# MeloForge Studio

MeloForge Studio е основа за създаване на песни и музикални видеоклипове с адаптивна Local-First / Smart-Hybrid / Cloud-Quality архитектура.

> Това е desktop alpha. Основните потоци за цяла песен и AI video са свързани, но за реална генерация са нужни стартиран ACE-Step engine и активен provider акаунт с актуални тарифи.

## Стек

- Frontend: React + TypeScript + Vite
- Backend: FastAPI + Pydantic + HTTPX
- Local LLM: Ollama / OpenAI-compatible local endpoint
- Cloud LLM: OpenRouter, Novita, NVIDIA NIM, Hugging Face Inference Providers
- Music: ACE-Step 1.5 asynchronous API (локално или собствен частен endpoint)
- Video: Novita Wan 2.2 async API
- Локален FFmpeg Composer: цяла песен с повтаряща се AI сцена, 16:9/9:16 експорти и отделен файл с текста
- Следващи модули: VoxCPM и InvokeAI

## Стартиране

Изисквания: Python 3.11+, Node.js 20+. За локално генериране стартирай ACE-Step 1.5 API.

1. За локална разработка копирай `.env.example` като `.env`. Инсталираното Desktop приложение създава `config.env` и локални данни в `%LOCALAPPDATA%\MeloForge Studio`.
2. Backend:

```bash
cd backend
python -m venv .venv
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
# Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
uvicorn app.main:app --reload --port 8000
```

3. Frontend в нов терминал:

```bash
cd frontend
npm install
npm run dev
```

UI: http://localhost:5173
API: http://localhost:8000/docs

## Windows приложение и инсталатор

За portable Windows build (без инсталатор) изпълни от корена на проекта:

```powershell
.\scripts\build-windows.ps1 -SkipInstaller
```

Резултатът е в `dist\MeloForge Studio\MeloForge Studio.exe`. Скриптът първо изгражда React интерфейса, след това пакетира локалния FastAPI сървър и UI в едно Windows приложение. То слуша само на `127.0.0.1` и отваря приложението в стандартния браузър.

За `Setup.exe` инсталирай Inno Setup 6 и изпълни:

```powershell
.\scripts\build-windows.ps1
```

Инсталаторът ще бъде в `release\MeloForge-Studio-Setup.exe`. Не включва модели, API ключове или потребителски файлове.

## Локален модел

Инсталирай Ollama, след това:

```bash
ollama pull qwen2.5:3b
```

В `.env` задай `LOCAL_LLM_ENABLED=true`, `LOCAL_LLM_MODEL=qwen2.5:3b` и `LOCAL_LLM_BASE_URL=http://127.0.0.1:11434/v1`. На RTX 2050 4 GB / 16 GB RAM това е ориентировъчен малък модел; възможно е част от изпълнението да се прехвърли към системната RAM/CPU и да е бавно. Реалният капацитет зависи от свободната памет и настройките на Ollama.

## Provider роли

| Доставчик | Роля | Base URL |
|---|---|---|
| OpenRouter | Унифицирано LLM API, избор и fallback между модели | `https://openrouter.ai/api/v1` |
| Novita | OpenAI-compatible LLM API и отделни async генеративни API | `https://api.novita.ai/openai` |
| NVIDIA NIM | Hosted LLM API Catalog | `https://integrate.api.nvidia.com/v1` |
| Hugging Face | Inference Providers; chat и task-specific модели | `https://router.huggingface.co/v1` |
| Ollama | Локален LLM | `http://127.0.0.1:11434/v1` |

Моделните ID-та са специфични за доставчика и трябва да се вземат от неговия текущ каталог.

## Режими

- `local_first`: локално първо; облак само ако е разрешен fallback.
- `hybrid`: локален модел за по-леки текстови задачи, а за останалите — най-евтиният настроен cloud модел с известни тарифи.
- `cloud_quality`: предпочитан cloud доставчик, но без заобикаляне на ценовия лимит.

## Ценова защита

Цените на cloud LLM се въвеждат в `.env` като USD за 1M input/output tokens. Системата добавя 25% резерв към предварителната оценка и блокира платената заявка, ако липсва тарифа или бюджетът се надвишава. Броят входни токени е приблизителен (около 1 токен на 4 знака), не е точен tokenizer. За video се задава цена на секунда според текущата тарифа.

## Music generation

MeloForge използва официалния асинхронен ACE-Step 1.5 API: `GET /v1/models`, `POST /release_task`, `POST /query_result`. Стартирай услугата и зареди модел; после отвори Music Studio → „Настрой музикалния engine“. За private/hosted endpoint въведи адреса и актуална цена за секунда. API ключовете се пазят локално, защитени от Windows DPAPI за текущия Windows профил. Локалният `127.0.0.1` endpoint се оценява с $0 API разход. Генерирането не започва преди изрично потвърждение на офертата в UI.

Ако полето за текст е празно, ACE-Step може да генерира текст/структура заедно с песента. Избраният език е български или английски; реалната езикова поддръжка зависи от заредения модел. След готовност на песента и Novita видеото, Video Studio сглобява пълната дължина с повтаряне на кратката сцена, записва 16:9 и 9:16 версии и предлага текста като TXT. Монтажът се изпълнява локално с FFmpeg и не изпраща нова платена заявка.

## Song pipeline и стандарти

1. **Текст.** ACE-Step чете структурата от тагове на отделни редове: `[Intro]`, `[Verse 1]`, `[Pre-Chorus]`, `[Chorus]`, `[Bridge]`, `[Outro]`, `[Instrumental]`. Текст без тагове се структурира автоматично (повтарящ се блок = припев). Предупреждение се показва, ако текстът е твърде дълъг/кратък за избраната дължина.
2. **Автоматичен текст.** На GPU под ~6 GB ACE-Step стартира без своя 5Hz LM, затова не може сам да напише текст. Бутонът „Напиши текст с AI“ (`POST /api/v1/music/lyrics`) ползва LLM router-а (Ollama първо, cloud само с тарифа и бюджет). Ако ACE-Step е стартиран с `ACESTEP_INIT_LLM=true`, отбележи го в настройките на engine-а — тогава се включват `thinking` и sample mode.
3. **Музикални параметри.** Caption = стил, инструменти, вокал, емоция. BPM, тоналност, размер и seed се подават като отделни ACE-Step полета (по препоръка на ACE-Step, не в caption).
4. **Генерация** в lossless WAV от ACE-Step; оригиналът се пази локално в `data/songs/<job>/raw.wav`, така че не зависи от временната папка на ACE-Step.
5. **Мастеринг** (FFmpeg `loudnorm`, ITU-R BS.1770 / EBU R128, two-pass, linear):

| Preset | Integrated | True peak | Употреба |
|---|---|---|---|
| `streaming` (по подразбиране) | −14 LUFS | −1 dBTP | Spotify, YouTube, Tidal, Amazon |
| `apple` | −16 LUFS | −1 dBTP | Apple Music |
| `broadcast` | −23 LUFS | −1 dBTP | EBU R128 радио/TV |

6. **Изход:** `master.wav` (44.1 kHz, 24-bit, stereo), `master.mp3` (320 kbps CBR, ID3v2.3 с заглавие, жанр и текст), `lyrics.txt`, `mastering-report.json` (измерване преди/след и флаг `compliant`). Видео монтажът използва мастерирания запис и реалната му дължина; AAC 256k / 48 kHz.

## Безплатен локален клип (визуализация)

Music Video → „Безплатен клип“ (`POST /api/v1/media/visualizer`) прави клип от мастерираната песен изцяло локално с FFmpeg, без AI видео и без разходи:

- анимиран градиентен фон в палитра „Неон“, „Залез“, „Океан“ или „Монохром“;
- визуализация, която реагира на звука: спектър, вълна или пулс (осцилоскоп), с меко сияние;
- заглавие и жанр с плавно появяване, лента за прогрес;
- по желание текст на екрана — таймингът е приблизителен (по брой думи), защото ACE-Step не връща времена на думите;
- 16:9 (YouTube) и 9:16 (Shorts/TikTok/Reels), H.264 + AAC 256k/48 kHz, 30 fps. Рендерът отнема ~2 мин. за минута песен (двата формата).

Платеният път (Novita Wan 2.2) остава: една AI сцена от 5–8 сек., повторена до дължината на песента.

## Готови песни (папка за публикуване)

Всяка завършена песен се копира автоматично в `Музика\MeloForge\<заглавие>\` с нормални имена: `<заглавие>.mp3` (320k с вграден текст), `<заглавие>.wav` (24-bit), `<заглавие> - текст.txt`, `само вокал` / `само музика` (ако са отделени), `информация.txt` (жанр, BPM, тоналност, LUFS) и подпапка `Клипове` с готовите видеа (визуализация и Atelier). Бутон „Отвори папката с песента“ под всяка песен. Друго място: `MELOFORGE_LIBRARY_DIR`. Стари песни: `python -m app.cli library`.

## Моят глас (клониране за пеене)

Готова песен може да бъде „изпята“ с твоя глас. Обработката е изцяло локална и безплатна:

1. **Demucs htdemucs** отделя вокала от музиката.
2. **Seed-VC** (модел за пеене, 44,1 kHz, с F0) преобразува вокала в тембъра от 10–30 сек. твой запис (zero-shot, без обучение). Мелодията, ритъмът и текстът идват от оригиналния вокал, затова работи на всеки език, включително български.
3. Новият вокал се изравнява по сила с оригинала, смесва се обратно с музиката и се мастерира по избрания стандарт. Изнасят се и отделните „Само вокал“ / „Само музика“.

Гласовият профил се записва от микрофона или се качва като файл и се пази само в `data/voices`. Създава се единствено след потвърждение, че гласът е твой или имаш изричното съгласие на човека.

Инсталиране (отделна среда, за да остане приложението леко; ~5 GB с torch и моделите):

```
git clone https://github.com/Plachtaa/seed-vc %LOCALAPPDATA%\Programs\Seed-VC
cd %LOCALAPPDATA%\Programs\Seed-VC
uv venv --python 3.10 .venv
uv pip install --python .venv\Scripts\python.exe torch==2.4.0 torchaudio==2.4.0 --index-url https://download.pytorch.org/whl/cu121
uv pip install --python .venv\Scripts\python.exe scipy==1.13.1 librosa==0.10.2 huggingface-hub munch einops transformers==4.46.3 soundfile pydub hydra-core pyyaml numpy==1.26.4 matplotlib tqdm demucs==4.0.1 descript-audio-codec==1.0.0
```

Ако `import torch` даде грешка за `fbgemm.dll`, липсва `libomp140.x86_64.dll` (OpenMP runtime на Microsoft). Сложи го в `.venv\Lib\site-packages	orch\lib` или инсталирай torch 2.4.1+.

Скорост на RTX 2050 (4 GB): отделянето на 100 сек. песен отнема ~1 мин. Първото преобразуване тегли и моделите (~2 GB), затова е по-бавно. ACE-Step и ComfyUI трябва да не работят едновременно с него.

**Дует и хор.** Под „Изпей с моя глас“ избери „Дует“ и втори глас. За всяка част на песента (куплет, припев, бридж…) избираш кой пее: глас А, глас Б, двата заедно, оригиналният AI глас или хор. Всяка част може да се разгъне „по редове“ и всеки ред да се даде на друг глас. Режимът „А + хармония“ и хорът добавят истинска хармония в тоналността на песента: терца, секста или квинта над мелодията. Нотите се разпознават от вокала (pYIN), а за всяка нота се избира интервал, който остава в гамата (напр. в ре минор: D→F, F→A, A→C). Изместването е с Rubber Band със запазени форманти, затова гласът не звучи като „катерица“. Хорът наслоява няколко леко разместени копия от наличните гласове плюс хармонията. Частите се откриват автоматично: Whisper (на процесора) разпознава вокала и го подравнява с текста. Същите времена на редовете влизат и в пакета за Atelier (`lyric_timing`). Дует с хор на 2:30 мин. песен отнема ~12 мин. на RTX 2050.

**Качество (измерено с Whisper върху вокала на „Кръчмата на Цеко“):** оригиналният AI вокал е с 22 от 23 разпознати реда. Соло с клониран глас дава ~0,80 съвпадение с текста срещу 0,86 при оригинала. Поправеният дует с хор дава 20 от 23 реда. Височината се сменя само с цели октави, защото Seed-VC мести самата мелодия и всяко друго изместване излиза извън тоналността. Най-естествено звучи, когато певецът в песента е от същия тип като твоя глас (мъжки/женски), а пробата е 15–30 сек. чист запис, по възможност изпят.

**Гласове от ElevenLabs.** Свържи ключа си. Пази се криптиран с DPAPI и не се връща към браузъра. Избери глас от своя акаунт. MeloForge взима ~250 символа говорна проба (от кредитите ти) и я записва като гласов профил, а пеенето е локално. Спазвай условията на всеки глас в ElevenLabs.

CLI: `python -m app.cli voices`, `voice-add me.wav --name "Моят глас" --i-own-this-voice`, `sing --song <id> --voice <id> --semitones 0 --out ./out` (дует: `--voice-b <id> --semitones-b 7`, хор в припевите: `--choir`).

## Клип в Atelier

Бутонът „Клип в Atelier“ (и `python -m app.cli clip <song id> --mode stills --local-only [--confirm]`) изнася пакет `meloforge.song/1`: `song.json`, `master.wav/mp3`, `lyrics.txt` и `vocals.wav`/`instrumental.wav`, подравнени проба по проба с мастера. Пакетът отива в Atelier (`atelier_base_url`, по подразбиране `http://127.0.0.1:8765`, само локален адрес). Atelier връща оценка на цената и нищо платено не започва без „Потвърди“. MeloForge следи напредъка и показва готовия MP4. Самостоятелен пакет: `python -m app.cli export-song <id> --to ./package`.

Друг път се задава с `MELOFORGE_SEEDVC_DIR`. Моделите (~1 GB) се изтеглят при първото пускане. На 4 GB видеокарта процесът върви последователно с ACE-Step. VibeVoice не се използва: прави само говор, официалното клониране е премахнато от Microsoft и лицензът е само за изследвания.

## Жанрове и актуални тенденции

Music Studio има 17 жанрови профила (поп, денс, хип-хоп, R&B, рок, инди, електронна, synthwave, фолк, балкан поп, латино, кънтри, метъл, соул/фънк, джаз, реге, филмова). „Анализирай хитовете“ (`POST /api/v1/music/trends`):

1. Зарежда текущата класация за жанра от публичния Deezer API (без ключ, регионална, кеш 6 ч.) — само заглавия, изпълнители, позиция, дължина, дата на издаване и BPM, когато е наличен.
2. Изчислява средна дължина, темпо и колко от песните са нови; предупреждава, когато класацията е доминирана от стари или сезонни хитове.
3. Избраният AI модел (локален или облачен, през бюджетната защита) прави кратък анализ: звук за ACE-Step, настроение, BPM, дължина, структура, теми и стил на текста. Без AI се използва профилът на жанра плюс числата от класацията.
4. „Приложи към песента“ попълва звука, настроението, BPM и дължината; „Напиши текст с AI“ използва темите и структурата.

Анализът описва общи тенденции: не се изтеглят текстове или аудио на чужди песни, а описанието за ACE-Step не съдържа имена на изпълнители или песни. За добър текст на български се препоръчва облачен модел (OpenRouter и др.) — един текст е няколко хиляди токена, т.е. под цент при повечето модели.

## CLI за агенти

CLI-то стартира същото API в процеса (не е нужен сървър) и връща JSON. Данните и настройките са общи с Desktop приложението.

```powershell
cd backend
.venv\Scripts\python -m app.cli readiness
.venv\Scripts\python -m app.cli lyrics --prompt "нощно пътуване, надежда" --language bg --duration 120 --out song.txt
.venv\Scripts\python -m app.cli song --title "Нощни светлини" --prompt "melodic synthwave pop, warm synth pads, male vocal" --lyrics-file song.txt --duration 120 --bpm 104 --key "A minor" --yes --out .\out
.venv\Scripts\python -m app.cli trends --genre pop          # --genre list за всички жанрове
.venv\Scripts\python -m app.cli master input.wav --preset streaming
.venv\Scripts\python -m app.cli jobs --kind song
```

Платен (ненулев) quote не се потвърждава без `--yes` и `--max-cost`. Кодове за изход: 0 успех, 1 грешка, 2 мастерингът е извън целта, 3 нужно е потвърждение на цена, 4 timeout.

## Състояние на разработката

- Включени са хардуерен детектор, provider registry, LLM router, budget guard, ACE-Step song flow, provider setup UI и Novita Wan 2.2 adapter.
- Цените все още се въвеждат ръчно; динамично обновяване на каталози/тарифи е следващ етап.
- Работите и настройките се пазят локално като JSON; следващи етапи са база данни/job queue, storyboard и синхронизирани субтитри.
- Не са включени API ключове, не се изпращат платени заявки при първо стартиране.

## Безопасност

В Desktop режим API ключовете се шифроват чрез Windows DPAPI и се пазят в профила на потребителя; provider settings не връщат ключове към UI. В разработка може да се използва `.env`, който не трябва да се commit-ва. Преди public deployment са нужни login, rate limiting, per-user secrets, audit logs и cloud spend caps.
