# Архитектура

Използваме modular monolith: React UI → FastAPI → Hardware Detector / AI Router → provider adapters. Няма нужда от микросървиси на този етап.

1. UI подава задача, режим, provider (по желание) и бюджет.
2. Hardware Detector проверява RAM и NVIDIA VRAM чрез nvidia-smi.
3. AI Router избира локален модел или облачен доставчик.
4. При cloud маршрут се изисква въведена тарифа за точния модел; липсваща цена блокира заявката.
5. Backend извиква адаптера и връща provider, model и usage.
6. Видео задачите се подават асинхронно към Novita Wan 2.2 и се следят чрез task ID.
7. Следващ етап: FFmpeg Composer за синхронизация и MP4 експорт.

## Режими

- local_first: локален модел първо; fallback според ALLOW_CLOUD_FALLBACK.
- hybrid: кратки текстови задачи локално при налични ресурси; иначе най-евтиният конфигуриран и тарифиран cloud модел.
- cloud_quality: PRIMARY_CLOUD_PROVIDER, но без заобикаляне на бюджетния лимит.

## Budget guard

Входните токени се оценяват приблизително като 1 токен на 4 знака, плюс максимум изходни токени. Цената се изчислява по тарифи USD/1M и се добавя 25% резерв. Това е предварителна оценка, не гарантира окончателна фактура. Доставчиците трябва да връщат usage за последващо фактическо отчитане.

## Security

Ключовете остават в backend env. UI получава само статус дали доставчикът е конфигуриран. Преди public deployment са задължителни user auth, rate limits, per-user secrets, audit log и лимити на cloud spend.
